# 暫停與恢復訂閱流程

## 適用情境

- 客戶說「我要出國一陣子」「先暫停」「這兩個月不會看」
- 客戶說「我要恢復」「提早開始看」
- 客戶要求暫停的期間或次數不符合規則

## 會用到的工具

`verify_identity`、`get_customer`、`search_policy`、`pause_subscription`、`resume_subscription`、`transfer_to_human`

## 步驟：暫停

1. **驗證身分**（作業規範 W1）。

2. **查詢目前狀態**：用 `get_customer` 取得 `status`、`billing_cycle`、`pause_count_this_year`。

3. **查詢規則**：用 `search_policy` 查「暫停」，確認知識庫 **P2-3** 的條件。

4. **逐項檢查資格**，**任何一項不符合就不能暫停**：

   | 檢查項目 | 資料來源 |
   |---|---|
   | 目前狀態是否允許暫停 | `status` |
   | 計費週期是否允許暫停 | `billing_cycle` |
   | 今年的暫停次數是否還有剩 | `pause_count_this_year` 對照 P2-3 的上限 |
   | 客戶要求的期間是否允許 | 對照 P2-3 允許的期間長度 |

5. **不符合資格時**：
   - 具體說明是**哪一項**不符合。
   - 期間不符合時，提供規則允許的選項讓客戶選擇。
   - 客戶要求規則以外的例外 → 依 **P3-5** 使用 `transfer_to_human`，不要自行破例。

6. **向客戶確認**（作業規範 W2）：暫停幾個月、暫停期間不扣款也不能觀看（P2-3）、期滿自動恢復。

7. **執行**：客戶明確同意後，呼叫 `pause_subscription`。

## 步驟：恢復

1. **驗證身分**，用 `get_customer` 確認 `status` 是 `paused`。不是暫停中就不需要恢復。

2. **查詢規則**：用 `search_policy` 查「恢復」（知識庫 **P2-4**）。

3. **向客戶確認**：恢復後立即生效並重新開始計費；並提醒依 P2-4，提前恢復**不會退還**已使用的暫停次數。

4. **執行**：客戶明確同意後，呼叫 `resume_subscription`。

## 常見錯誤

| 錯誤 | 正確做法 |
|---|---|
| 年繳客戶也幫忙暫停 | 檢查 `billing_cycle` 是否符合 P2-3 |
| 今年次數用完仍然暫停 | 檢查 `pause_count_this_year` |
| 客戶要暫停 3 個月就直接呼叫工具 | 期間不符規則，提供允許的選項 |
| 只說「不能暫停」不說原因 | 具體說明哪一項條件不符合 |
